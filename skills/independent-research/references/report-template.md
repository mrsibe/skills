# 研究报告模板（按需选用）

本文件提供输出结构，**不要求逐栏机械填满**。用户指定格式、字数或用途时，以用户需求为准。所有示例占位符都应替换为实际证据；找不到证据时标注不确定性。

## 快速版：理解概念或判断一句流行观点

```markdown
**结论（附适用条件）**：……【置信度：高/中/低】

**What**：它是什么？不是什么？（原始材料）
**Why**：出现前的方案和痛点？（时间背景）
**How**：最关键的实现机制是什么？为何有效？
**Trade-off**：改善了什么，引入了什么成本，适用于哪些场景？

**外部反证**：最有力的反对/限制条件，以及它是否改变结论。
**仍待验证**：一项最值得验证的不确定性。
**主要来源**：一手资料 + 独立材料（有链接或可核验定位）。
```

## 标准版：系统调研

```markdown
# [研究对象] 调研

调研范围：[版本 / 时间 / 具体问题]
研究目标：[用这份研究决定什么]

## 结论摘要
- 核心判断（有前提，不夸大）
- 最重要的收益和代价
- 适用 / 不适用场景
- 置信度与最大不确定性

## 1. What — 是什么
定义、边界、重要能力、证据；与常见误解的区别。

## 2. Why — 为什么出现
历史背景 → 旧方案 → 旧方案缺口 → 新方案目标。

## 3. How — 原理是什么
总体流程 → 关键机制 → 因果解释 → 实现/实验依据 → 限制。

## 4. Trade-off — 得到什么，牺牲什么
以真实替代方案为基线，比较收益、成本及适用条件。

## 5. 外部评价与反证
第三方的具体支持证据；最强反对证据；版本和样本偏差。

## 6. 独立判断及修正
- 第一轮初判：……
- 第二轮得到的新证据：……
- 最终结论：维持 / 限定 / 修正 / 推翻；原因是……

## 7. 下一步验证
假设、对照、环境、指标、判据；标明已执行还是计划执行。

## 来源与证据局限
按关键主张引用原始资料，并披露无法核验或存在冲突的内容。
```

## 深入版：研究论文或技术选型

在标准版上添加：

- 研究问题与评价指标，以及旧方案基线（选型需要明确目标工作负载）。
- 时间线和关键前置工作：解决的是哪个具体历史难题。
- 逐模块机制：重要伪代码、公式解释、调用栈或数据流。
- 实验复现：环境、版本、数据、对照组、原始记录和分析。
- 消融与失败案例：为何认为关键模块带来收益。
- 决策矩阵：不同约束下分别推荐什么（不要将个人偏好包装成客观评分）。
- 未解决问题与未来研究方向：按“影响决策程度 × 验证成本”排序。
