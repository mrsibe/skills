# paper-reading 手动回归测试

这些用例验证触发边界、阅读深度和证据约束，不是已经取得的测试结果。**全部用例目前未运行。**

## 执行方法

1. 记录 Skill 文件的 Git 修订；未提交时保存所测文件快照或哈希。固定客户端、模型版本、工具权限与输入材料。
2. 每个用例使用独立会话。触发测试让客户端正常发现元数据，不显式调用 Skill；通过加载日志或工具轨迹确认是否触发，无法观察时记录“触发情况未知”，不要只凭回答猜测。
3. 正例另做一次显式加载测试，检查工作流行为。反例不显式加载 Skill。
4. 网络用例先固定论文版本并保存所用材料；无法获取时记录阻塞，不把降级回答当作全文分析通过。T2 则必须禁用联网和全文访问。
5. 逐项检查验收条件，保留回答及工具轨迹。任一必要条件不满足即失败；缺少证据则记录未验证。
6. 若评估效果，另用无 Skill 的干净环境运行相同任务作为 baseline，保持模型、材料和工具一致，重复运行并按相同标准比较。

## 正向用例

### T1：快速筛选，不升级精读

输入：

> 帮我快速筛选 Attention Is All You Need（https://arxiv.org/abs/1706.03762），我想了解序列建模，200 字左右告诉我核心想法和是否值得继续读，不要推公式。

验收：触发并选择 `skim`；简短说明问题、核心想法、主要证据与条件式建议；标明版本和阅读范围。不能为了完成自检而展开推导、逐节精读或完整 baseline 审计；不主动读取补充材料。关键事实附可核对位置，不编造页码。

### T2：仅有摘要，不编造实验

输入（合成材料，仅用于测试证据边界，不是真实论文）：

> 请解释下面论文摘要的机制与证据，不要联网。标题：ToyCache。摘要：我们提出用查询频率驱动的缓存策略降低检索延迟。在内部工作负载上，作者报告相对 LRU 延迟下降。没有提供正文、图表、数据或代码。请说明实验能证明什么、还缺什么。

验收：触发 `understand`；明确只有摘要，版本未知；将延迟下降表述为作者声称。指出缺少实验条件、数值、指标定义与方差；不发明数据集、改进百分比、章节位置或具体算法。

### T3：深度阅读，定位公式和数字

输入：

> 精读 Attention Is All You Need（https://arxiv.org/abs/1706.03762）。重点解释 scaled dot-product attention 的缩放因子，并选取一项主要翻译实验结果，说明指标、baseline 和比较条件。只分析这些部分。

验收：选择 `deep`；记录所读版本；解释变量、维度、缩放直觉与推导前提；将推断与论文原话分开。数字和公式位置能够回到所固定版本验证；不展开无关背景或捏造独立实验。

### T4：不同条件不直接排名

输入（合成材料）：

> 比较两篇论文的下面摘录，判断哪个方法更好。不要联网。
> 论文 A，版本未知，表 1：在数据集 X 上，单张 GPU，batch=1，吞吐 100 samples/s。
> 论文 B，版本未知，表 2：在数据集 Y 上，8 张 GPU，batch=64，吞吐 600 samples/s。
> 只有这些摘录。

验收：选择 `compare`；统一列出数据、硬件、批量与证据范围；明确不能据此得出 B 方法更优或单卡更快。不得虚构质量指标，也不得将简单除以 GPU 数当作公平单卡测量。

### T5：小预算复现规划，不冒充实测

输入：

> 我只有一张 8GB GPU，想验证 Attention Is All You Need（https://arxiv.org/abs/1706.03762）的一个核心机制。请设计最小实验，不运行代码、不下载数据、不安装依赖，也不要求复现论文完整指标。

验收：选择 `reproduce` 并读取复现协议；区分概念验证与结果复现；给出单一假设、baseline、受控变量、指标、预算估计、否证和停止条件。预算估计不是测量值；不执行代码或环境变更，不报告成功或实际指标。

## 不应触发的反例

| 编号 | 输入 | 验收 |
| --- | --- | --- |
| N1 | 把这句论文摘要翻译成中文，不要分析：We propose a cache policy for retrieval. | 只翻译，不启动论文阅读流程。 |
| N2 | 从下面文本提取参考文献，保留原样，不做论文分析：[1] A. Author. Toy Study. 2024. | 仅提取给定条目，不添加阅读结论。 |
| N3 | 把这段文本转成 Markdown 标题和段落，不分析内容：标题 Toy Study；正文 We study caching. | 只转换格式，不追加方法或证据分析。 |
| N4 | 找到 Attention Is All You Need 的官方论文地址，只返回链接。 | 仅查找并返回链接，不启动精读。 |

## 混合意图

M1：`先翻译这句摘要，再解释它能否证明因果关系：Our cache policy correlates with lower latency on an internal workload. 不要联网。`

验收：可以触发；翻译部分忠实简短，分析部分指出相关性不等于因果性、缺少受控实验；不展开整篇论文模板。
