# Skill 测试

当前没有 Skill，也没有测试用例或自动化测试执行器。

后续按 `tests/<skill-name>/` 组织资料，每个 Skill 至少记录：

- **正例**：应触发该 Skill 的真实任务与必要输入。
- **反例**：看似相关、但不应触发的任务。
- **验收标准**：可观察的行为、输出约束和失败条件。
- **回归案例**：已出现的问题及其复现条件。

评测记录应包含 Skill 修订、客户端与模型版本、输入、运行方式、实际输出和结论。对照实验需区分 baseline 与 candidate；未运行的案例标记为未验证，不得当作成功。

测试输入和输出不得包含凭证、个人隐私或内部业务数据。自动化工具与 CI 在实际有可验证内容时再引入。
